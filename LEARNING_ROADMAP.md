## 4. Main Personal Project – News Sentiment Analyzer

**Project Goal:** Develop a Python application that retrieves news articles through a News API and analyses their sentiment.

**Planned development stages:**

1. Learn how to retrieve news articles using an API.
2. Process and clean article text using Python.
3. Implement basic sentiment analysis.
4. Display positive, negative and neutral sentiment results.
5. Upgrade the application using machine learning or NLP.
6. Improve the interface and document the project on GitHub.

**Project constraint:** The application will not include a database or persistent storage component.

**Expected outcome:** A functional AI/Data Science project demonstrating API integration, Python programming, text processing and sentiment analysis.
